# **App Name**: Shopee Clone

## Core Features:

- Header Component: Display a sticky header with the Shopee logo, coupon information, and a promotional banner.
- Image Carousel: Implement an image carousel to showcase product images with navigation buttons and indicators.
- Price and Offer Display: Showcase the product's original price, discounted price, discount percentage, and a countdown timer for the offer.
- Call to Action Buttons: Design clear and attractive call-to-action buttons for purchasing.

## Style Guidelines:

- Primary color: Shopee Orange (#EE4D2D) to maintain brand recognition and create a sense of urgency.
- Background color: Light orange (#FFF2E7), a desaturated variation of Shopee Orange to create a cohesive and visually appealing backdrop.
- Accent color: Yellow (#FFE97A) for highlighting discounts and important information.
- Body font: 'PT Sans', sans-serif, for clear and readable text throughout the application.
- Headline font: 'Space Grotesk', sans-serif, for headings and titles, providing a modern and bold look.
- Use simple and recognizable icons for navigation and interactive elements.
- Maintain a clean and organized layout with clear sections for the header, image carousel, and product details.
